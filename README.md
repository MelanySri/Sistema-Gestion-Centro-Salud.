
# Sistema de Gestión del Centro de Salud

## Descripción
Proyecto desarrollado en Python para gestionar los registros de un centro de salud ficticio.

## Funcionalidades
- Registro de pacientes.
- Registro de médicos.
- Registro de citas médicas.
- Búsqueda de registros por código.
- Registro de atenciones médicas.
- Búsqueda de médicos por especialidad.
- Validación de datos y códigos duplicados.

## Tecnologías utilizadas
- Python

## Ejecución
Para iniciar el programa, ejecutar:

```bash
py main.py
```

## Datos
El sistema utiliza información ficticia con fines académicos.
